# 🚨 vetrecall-site

Публичная витрина радара [VetRecall](https://github.com/shray77/vetrecall) на GitHub Pages.

**Открыть дашборд: [shray77.github.io/vetrecall-site](https://shray77.github.io/vetrecall-site/)**

## Что внутри

- `index.html` — дашборд: карточки сигналов (отзыв/брак красным, вспышки янтарным), совпавшие ключевые слова, поиск, фильтры по типам, счётчики. Внешних CDN нет.
- `signals.json` — **перезаписывается автоматически воркером vetrecall** после каждого скана (крон 20 минут чётного часа — сразу после инжеста ФСВПС в rss-core). Руками не редактировать.

## Откуда данные

```
Россельхознадзор RSS (3 ленты)
  → rss-core: инжест, дедуп, D1         (приватная репа)
  → vetrecall: keyword-классификатор    (приватная репа)
  → vetrecall-site: этот дашборд        (вы здесь)
```

⚠️ Это скелет: ключевые слова дают и ложные срабатывания (новость **про** фальсификат ≠ отзыв серии). ИИ-фильтрация и проверка номера серии — в роадмапе воркера.
